# 🥗 ChefGuard - Gestor de Menú y Congelador Familiar

Aplicación web progresiva (PWA) para organizar el menú semanal y llevar un control exacto de las raciones congeladas en el hogar.

## 🚀 Características
- **Control de Stock de Guisos:** Suma y resta raciones de alubias, lentejas, pavo, pescado, etc.
- **Vista Limpia:** Muestra únicamente alimentos que tengan raciones disponibles (> 0).
- **Informe del Domingo (21:00h):** Muestra automáticamente al abrir la app un resumen de consumo e inventario.
- **100% Funcional Offline (PWA):** Instálala en tu smartphone como una app nativa.

## 📦 Cómo subir a GitHub y publicar gratis:

1. Crea un repositorio nuevo en GitHub (ej. `chefguard-app`).
2. Sube los archivos descomprimidos de este ZIP.
3. En GitHub, ve a **Settings** > **Pages**.
4. En *Branch*, selecciona `main` y guarda.
5. ¡En 1 minuto tendrás un enlace público HTTPS para usar la app en tu teléfono!
